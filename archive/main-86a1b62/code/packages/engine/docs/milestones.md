# 里程碑与实现边界

## M0：独立执行骨架（已实现）

独立 package、分层上下文、受限声明编译、原子确定性转移、合法命令、带种子模拟、逐步重放及合成反例测试。不依赖旧引擎。尚无真实游戏规则覆盖。

## M1：内容和剧本模型（待实现）

实体与身份分离、区域、目标查询、配置约束、规则包组合、来源与版本绑定。验收：新增一个使用已有操作的角色仅改内容数据及独立用例。

## M2：完整结算语义（待实现）

时机、生命周期、次数消耗、禁止与替代、同时组、中途选择、继续位置。验收：同一快照的同时效果及中途选择在 CLI 中可复现，并拒绝未明确的冲突。

## M3：首个真实剧本（待实现）

按 migration.md 从经审阅事实逐条录入。验收：全部所需规则均有来源、实现和独立预期；每日流程、轮回、终局闭环；缺失规则阻止运行。

## M4：对抗验证与客户端适配（待实现）

可见性投影、无信息泄漏的可操作范围、失败缩减、覆盖报告及有界探索。先验收，再替换 Web 调用。正式联机的认证与并发序号验证属于宿主适配层。

每一阶段明确已实现与未实现。M0 的合成测试通过不能提升为 M3 的游戏规则正确性。
