# 陪同GUI测试

先读 [测试说明](../../../lunhui-engine/docs/gui-testing.md)。由人类操作，Agent 协助诊断。

1. 明确本轮增量、运行版本、页面和待验收行为；启动或复用人类指定的本地服务，保留当前对局。
2. 列明实际可用的日志来源与采集方式。当前只有浏览器开发日志读取和服务终端输出；统一持久日志/问题标记/后台唤醒尚未实现，不能宣称已经持续监视。需要定时唤醒时按用户要求配置，不能以结束回复后仍在监听作承诺。
3. 交给人类操作。观察阶段不主动点击、刷新、重置、抢焦点或热更新；用户要求协助某个操作时仅完成该操作。
4. 出现问题时记录时间、动作、实际/预期、版本及可用日志和截图，区分预期拒绝和故障。先保留现场，再进入修复。
5. 将可重复反馈转换为版本化用例，程序回归通过后重新部署，交由人类复验。
6. 只有人类明确确认才能记录“人类验收通过”；日志无异常、截图正常或自动测试通过均不代替确认。
