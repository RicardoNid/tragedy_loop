TRAGEDY LOOP / THROWAWAY LOGIC PROTOTYPE / 01

一局游戏，六个状态面板

以 FS 官方入门剧本《はじまりの脚本》贯穿三次轮回：检查行动、权威状态、内部结算、视图、观察历史、推论能否完整描述一局游戏。点击每一步，查看同一个事实如何进入不同人的视野。

设计评估原型 · 含完整剧透 · 待设计者验收。这里的选择是教学编排，不代表最优策略；只有本剧本涉及的规则子集，未实现通用 FS 引擎或完整解空间求解器。全部状态仅保存在内存。

回看是实验台重放，不是游戏内撤销。

01 · 权威盘面 设计者全知

剧本、资源、次数与流程栈

02 · 视图 按观察者投影

当前观察者的手牌与轮回资源

03 · 输入与内部结算 设计者全知

动作不等于效果。秘密来源只在这里出现，不直接复制进主人公历史。

04 · 直接观察历史

与上方视图使用同一个观察者。历史只追加；推论不写入此区。调试步号用于设计者对齐，不属于玩家可观测语义，也不参与候选世界比较。

05 · 推论与解空间约束

仅按主人公历史运行有限示例推理。结论健全性可核查，算法不完备；没有候选世界数量，没有概率，没有读取秘密身份来补答案。

06 · 自由交互

在当前阶段尝试另一项输入。成功后进入自由分支；可重新开始导览恢复固定对局。所有按钮都经过同一规则入口。

自由分支覆盖出牌、系统推进及两项本局使用的好感能力。其他角色的可选能力未开放为自由按钮；完整导览内的剧作家身份能力单独可见。

逐步导览

每项是实际输入。可点击任意步骤从开局重放到该处；秘密策略说明仅供设计者阅读。

本次要检视的概念

词语在这个原型中的具体位置
权威状态固定剧本、盘面、实体牌的持有/暗置/弃置、日与轮回、能力次数、待回应选择、输赢。
行动出牌、发动能力、回应拒绝、选择放弃。系统推进是调度输入，标有 SYSTEM。
内部结算真实身份检查、秘密能力来源、同时批次、失败原因；保留完整因果。
观察注册谓词 + 具名参数 + 获知时点 + 有效时点 + 同时组；通过固定模板变为中文。
历史 / 视图历史保存获得过什么；视图显示现在获准知道什么。剧作家也不知道未翻开的主人公牌。
推论 / 公开根据死亡反推身份是推论；好感能力告知身份是直接观察。两者来源不同。
窗口阶段结束只保证该阶段规定的公开效果完整；没有观察到暗中能力来源，不等于它不存在。
逻辑语句与自然语言的约定

语句形状为 {op: "atom", predicate, args}。实体使用固定 ID，数值使用整数；显示名只在模板渲染时替换。独立的角色身份、主规则、副规则、事件犯人各自形成一条观察，不能把整份秘密剧本当作一个不可分的信息点。

注册谓词（示例）参数类型固定中文模板
CharacterAt角色 ID × 地点 ID{角色}位于{地点}
CounterEquals角色或地点 ID × token 类别 × 非负整数{目标}的{类别}为{值}
CardFace出牌者 ID × 牌型 × 目标 ID × 牌位 ID{出牌者}的牌{牌型}位于{目标}
AbilityResponse角色 ID × refused / accepted剧作家拒绝 / 接受了{角色}的能力声明
RoleRevealed角色 ID × 身份 ID依能力正式公开：{角色}为{身份}
WindowClosed阶段 ID × 完整性契约{阶段}观察窗口关闭；完整范围由契约给出

自然语言函数只消费已筛选的语句及公共词典；不能回读真实身份生成解释。内部事件中的来源不是自然语言补全素材。调试 revision 和事件 ID 是设计者元数据；玩家历史比较需要去除这些索引，保留语义语句、逻辑时点与同时关系。本原型只演示有限谓词，不实现通用布尔约束语言和 schema 校验器。

本局来源、版本与实现边界

主要来源：BakaFire 官方十周年站的入门套件，2021-11 文件：script_sheet(a5).pdf 第 1 页、summary(a4).pdf 第 1 页、data_token_chara(b4).pdf 第 1 页、instguide.pdf 第 5–8 页。下载与核对日期：2026-09-26。

官方设定：FS、三轮三天、六名角色、无特殊规则、第三天自杀；身份配置见全知盘面。套件属于官方 5th 入门素材；项目按用户指定叠加十周年“拒绝不耗次数”裁定及主人公共享视野。没有宣称已经实现所有十周年增量规则。本例不涉及傀儡等其他模组效果。

采用原型自己的动作序列，未复制官方教学对局或故事文案。中文显示采用项目常用译名：密谋对应暗躍，不安对应 Paranoia，好感对应友好。

支持本局的卡牌、强制杀人狂、可选杀手、主谋、传谣人、职员及男学生好感技能、自杀事件、重置及 FS 结局；其他好感技能暂不开放。能力次数按日 / 轮回分别建模；本局使用的职员与男学生技能按日计数。没有完整 SMT/SAT 推理、最优策略搜索、网络、数据库或玩家权限隔离服务。

角色死亡保留 token；强制效果按同一前态收集后同时落地；结束一轮先结算再重置。第 3 轮仍失败则剧作家胜，FS 无最后猜测。领队在每日指定阶段轮换；中途失败不执行尚未发生的轮换，跨轮保留当前领队。
