反向运算

  1. 由原生 RuleProgram、Ability、Step 及宿主窗口读取规则。为每个已进入的强制步骤绑定执行者、时点、门槛、全部合法目标、用量及可见性。可选动作的跳过分支必须保留。
  2. 只展开与新增公告或闭合窗口有关的局部变量。每条分支同时保存制作命题和运行时绑定。在入口快照上计算整批替代、抵消、护卫与公开净变化，然后在下一步快照上求后续连锁。
  3. 窗口开放时只检验已送齐批次是否为合法轨迹的前缀。正常闭合时要求整段相容。空记录也是一种输入；若任一合法选择能产生空记录，就保留该分支。提前结束时只闭合已明确完成的子步骤。记录缺口、绑定缺失或预算截断保留未排除的解释。
  4. 反推得到的是“可行分支的析取”，每支内部仍是整组条件的合取。向 Relations 写入排除子句，附上规则、入口盘面、窗口闭合证据和首次不相容序号。仅在所有分支对某类事实均有要求时才投影限定集合。无可行分支时报告矛盾并停止单格传播。
  5. 新证据若禁用了旧分支的最后一种静默选择，只重查依赖它的窗口；固定制作命题跨轮继承。记录检查过的规则、局部选择数、缓存命中与未决原因。

沉默能够说明什么

MC 心理医生在 EX≥1 时必须选择同区另一名角色。若每个合法目标都有不安且没有替代或抵消，完整窗口中无人减少不安，就能排除该角色为心理医生。若有零不安目标，合法选择它即可静默。EX 为零、没有目标、进入阶段后提前结束，都不能沿用前一项排除。参见MC FAQ 第 13 行。

特别需要复核多来源同批的公告归属。现有 silentGhosts、silentTherapists 会按受影响目标移除对应待检查项；该操作本身无法证明每一个重叠来源均已兑现。反推时应联合比较实际净变化与每种来源分配。例如两次移除作用于同一枚不安，可以只显示减少一枚；目标原有三枚、两次都移除且没有抵消时，则应显示减少两枚。此项属于需要构造真实对局复核的风险。

原型及接入验收

离线反向匹配原型接收局部完整解释及其可能公开轨迹，返回排除分支、联合替代关系和矛盾。回归比较开放、闭合、缺口、连锁和不完整枚举。轨迹目前由固定用例提供；运行时适配器、来源联合分配、依赖失效及 UI 来源投影尚未接入。

接入前应为每条强制规则测试门槛两侧、空目标、可静默目标、正常闭合和中途结束。复合测试应覆盖从者替死与两次攻击、御神木与心理医生同批、诅咒返回后的连锁，以及同一批次拆开发送。逐前缀以独立局部穷举核对联合可行性，再比较串行追加、合法批次追加与从开局重放；重复输入的新增来源与组合计数均应为零。
