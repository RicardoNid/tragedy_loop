# 模组审阅编辑器

本项目提供一个本地 Web 编辑器，用于审阅和保存 `module.pdf` 拆出的 8 个惨剧模块表格。

## 启动

```bash
uv run tragedy-loop
```

打开：

```text
http://127.0.0.1:5173/editor.html
```

身份特性池子页面：

```text
http://127.0.0.1:5173/traits.html
```

角色卡编辑器：

```text
http://127.0.0.1:5173/characters.html
```

## 编辑目标目录

编辑器只读写以下目录中的 Markdown 文件：

```text
facts/source_material/reference/module/modules/
```

本地服务端会限制保存路径，前端不能通过该 API 写入其它目录。

身份特性池保存到：

```text
facts/source_material/reference/module/identity-traits.md
```

模块原图功能保留在编辑卡片标题栏中，可以在“编号/原页”之间切换，并通过“查看”弹出大图或通过“新标签”打开；主编辑区域不显示原图预览，以便给表格审阅留出更多空间。

## 每个模组需要的要素

每个模组审阅稿固定围绕三张核心表组织。

### 规则表

字段：

- `规则类型`
- `规则名`
- `登场身份`
- `追加规则`

用途：定义模组使用哪些规则、每条规则下登场的身份，以及该规则带来的失败条件、强制处理或额外能力。

`规则类型` 只能选择 `规则Y` 或 `规则X`。`登场身份` 在编辑器中是一个列表，每一项由 3 个下拉框组成：

- 身份：来自当前模组身份表的 `身份名`
- 数量：`1` 至 `5`
- 数量规则：`默认`、`最多`、`至少`

保存到 Markdown 时，`登场身份` 会写成 `身份-数量-数量规则`，多项之间用中文分号分隔，例如 `主谋-1-默认；邪教徒-1-默认`。First Steps 的“最黑暗的剧本”中，暴徒会保存为 `暴徒-2-最多`。

### 身份表

字段：

- `身份名`
- `数量上限`
- `身份特性`
- `能力`

用途：定义模组可用身份、身份数量限制、无视友好/不死等身份特性，以及剧作家或强制能力文本。

`身份特性` 在模组编辑器中是一个列表，每一项从公共身份特性池下拉选择。公共池由现有 8 个模组身份表中的身份特性并集初始化，并可在 `traits.html` 中维护 `名称` 与 `解释`。保存到 Markdown 时，多项之间用中文分号分隔，例如 `无视友好；不死`。

### 事件表

字段：

- `事件名`
- `事件效果`

用途：定义模组可用事件，以及事件发生后的结算效果。

## 保存格式

编辑器保存后仍写回 Markdown，保留人工审阅友好的结构：

```text
# <模组名> - 模组信息审阅稿

状态：待人工校对
页图：`../pages/page-XX.png`
标注图：`../annotated/page-XX-blocks.png`

## 规则表
...

## 身份表
...

## 事件表
...
```

结构化运行时数据后续从人工校对后的 Markdown 派生到 `facts/structured/modules/`。
