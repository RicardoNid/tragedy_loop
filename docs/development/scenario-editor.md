# 剧本审阅编辑器

本项目提供一个本地 Web 编辑器，用于审阅和保存剧本信息。

## 启动

```bash
uv run tragedy-loop
```

打开：

```text
http://127.0.0.1:5173/scenarios.html
```

## 编辑目标

编辑器读写：

```text
facts/source_material/reference/scenarios/scenarios.md
```

当前初稿从 `facts/source_material/reference/剧作家之书/semantic-review.md` 的“剧本集”章节提炼。`facts/source_material/` 默认不进入 Git，符合本项目对扫描件、OCR 与审阅稿的本地资料约定。

## 剧本共性要素

剧本目录围绕三类信息组织：

- 公开概况：`剧本名`、`作者`、`使用模组`、`轮回选项`、`每轮天数`、`讨论`、`难度`、`特有规则`、`公开事件`
- 非公开真相：`采用规则`、`角色身份`、`事件当事人`、`剧作家胜利条件`
- 来源与摘要：`页图`、`来源`、`剧本特征`、`故事摘要`、`剧作家指引`、`备注`

## 模组约束

剧本的 `使用模组` 决定可选规则、身份和事件：

- `Rule Y` 下拉只来自当前模组规则表中的 `规则Y`。
- `Rule X1` 与 `Rule X2` 下拉来自当前模组规则表中的 `规则X`，并额外允许 `无`。
- 角色身份下拉来自当前模组身份表，并额外允许通用身份 `平民`。
- 事件和公开事件下拉来自当前模组事件表。

切换剧本模组时，编辑器会把已不属于该模组的规则、身份和事件重置到当前模组的可用选项。

## 保存格式

编辑器保存后写回一个 Markdown 审阅目录，包含：

```text
## 剧本目录
## 采用规则
## 角色身份
## 事件
## 公开事件
## 剧作家胜利条件
```

这种扁平表格格式便于人工审阅，也便于后续派生到 `facts/structured/scenarios/` 或规则核心数据。
