验证范围

逐步比较完整引擎状态 SHA-256，以及剧作家、三位主人公和主人公共享视图。执行预算为 1、7、10000；在决策边界和内部暂停点进行 JSON 保存与恢复；验证输入不被修改、命令重试不产生重复效果。另由回归测试验证标准 replay / runBatch API 和被篡改历史的拒绝。

相同结果的前提：相同规则包摘要、初始配置、LL 秘密座位分配、行动顺序及命令。规则升级时须审阅基线差异，不能自动将旧历史当成新版本真值。

来源与版本

官方身份由本地 Wiki 官方目录核对；配置沿其链接的剧本数据库读取，LL 使用规则手册第 18 页链接的官方样本英译文档。不是所有资料都由发行方直接托管。FS 已对照官方体验版剧本图核对。MZ 的数据库误将职员自白写为第 4 天；依据 Midnight Circle 发行方手册第 6 页改为第 3 天。AHR 采用数据库的 3 轮版本，本地目录同时列出 4/3 轮。所有测试不叠加十周年增量规则。BTX Plus 为独立组合模组，当前引擎 Module 契约不包含它，未冒充 BTX 覆盖。

本验证证明这些历史可运行且可重放；不证明所有可能行动组合或全部规则语义均正确。无 Web GUI 自动验收；图文与规则人工验收：待人类验收。测试文件含完整秘密配置和动作，应仅用于测试、维护和全知复盘。
